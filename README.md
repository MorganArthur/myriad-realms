# 万象之境

一款原创的像素世界模拟器。玩家可以塑造地形、创造居民、赐予祝福或降下灾难；居民会自行探索、建立聚落、形成王国并繁衍。

王国会围绕聚落采集粮食、木材与石料，并根据人口和资源建造住宅、农场、伐木场、采石场及兵营。不同王国之间会形成和平、同盟或战争关系；战争期间士兵会集结、进攻并占领敌方聚落。世界中同时存在会觅食、繁衍、捕猎和迁徙的野生动物生态。

## 文明系统

- 资源：草原与农场生产粮食，森林与伐木场生产木材，山地与采石场生产石料；基础储粮能力随人口、聚落和农场增长，过量库存会自然损耗。
- 实体建筑：建筑拥有独立坐标、耐久、建造纪元和所属聚落，可在地图上直接观察；灾害、火灾和战争会损伤或摧毁具体建筑，建筑师会优先维修危房。
- 城市设施：住宅提高人口容量，农田、伐木场和采石场强化对应生产，兵营扩大正规军上限；道路加速移动和建设，城墙强化防御与安全，市场扩大商贸，港口提供水域粮食和贸易，神殿改善幸福、治疗与恢复。
- 仓储：仓库扩大三类聚落库存和商队装载量，同时提高国家储粮能力；建筑损毁后相应容量会立即下降。
- 城市生长：聚落会根据战争、住房、粮食、地形、人口和当前库存选择能够负担且有合法地块的建设项目，并把道路逐段延伸到外围设施。
- 职业：成年居民会根据聚落资源、建筑、疾病和战争需求，在农民、伐木工、矿工、建筑师、商人、治疗师与士兵之间动态分工；儿童成年后进入劳动力队伍。
- 民生：每位居民拥有营养、住所、安全与健康需求，工作、战争、灾害、拥挤和疾病会共同影响幸福度及生命状态。
- 饥荒：粮食按人口持续消耗，低储备会触发并逐步加剧饥荒，降低幸福度、健康和生育率；恢复安全储备后饥荒自动结束。
- 扩张：人口和资源充足的王国会派出拓荒者建立新聚落并扩张领土。
- 外交：边境摩擦、经济差距和随机事件会改变关系，国家能够结盟、宣战与议和；同盟提供贸易增益。
- 战争：国家会按人口与兵营进行战时动员，把士兵编入军团，由将领率领攻击敌军、围攻聚落和占领领土；失去全部聚落的王国将覆灭。

## 文化与科技

- 每个国家拥有独立文化名称与起源精神，并记录共同体、自然、技艺、尚武、商贸和信仰六类价值观；价值观会随政体、政策、职业、战争、森林和城市设施缓慢演变。
- 文明会根据农田、森林、矿业、军队、市场、港口、神殿和科技水平形成丰收礼俗、林地守望、石工秘传、勇士信条、商旅行会与济世教团，传统会提供永久的特色加成。
- 农耕学、工程学、冶金术、航运术、医药学和行政学各有三级研究，研究点由成年人口、工匠、治疗师、商人、聚落和文化精神共同产生。
- 科技不是展示数值：它会实际改变粮食和仓储、建筑成本与耐久、军队攻击与攻城、商队运量与速度、治疗与抗疫、税收与合法性。
- AI 会依据饥荒、战争、瘟疫、动乱和港口发展调整研究方向；玩家可在国家详情中点击科技，将研究方向锁定 10 个纪元。
- 跨国商队会带来文化交流，使双方价值观逐渐互相影响；叛乱政权会继承母国的部分传统和技术，同时形成新的文化名称。

## 国家与社会

- 人类、精灵、矮人和兽人国家分别以君主制、长老议会、行会共和国和氏族联盟起步；政权危机可能推动政体改组。
- 国家拥有国库、税收、合法性、福利覆盖与社会动乱；税制、民生和军事三组政策会同时影响财政、幸福、动乱与征兵规模。
- 居民会根据年龄、职业与军职形成权贵、商贾、匠师、平民、军户和眷属阶层，不同阶层对政体、税收和战争方针有不同反应。
- 玩家可在国家详情中直接调整政策，也能用神力安抚或煽动民心；AI 国家会依据财政、饥荒、战争与动乱自主修正政策。
- 长期低幸福、饥荒、重税、战争疲劳和福利断供会积累地方动乱。高动乱聚落可能脱离母国，带走居民、领土、物资与部分国库，并建立新政权发动内战。

## 军事系统

- 军团拥有集结地、战役目标、将领、士气、补给、伤亡与攻城进度，会在集结、推进、交战、围城和撤退之间切换。
- 民兵、步兵、弓手、骑兵和攻城兵拥有不同的攻击、防御、射程、速度、补给消耗与攻城能力；兵营、市场、伐木场和采石场会影响兵种编制。
- 军团从附近友方聚落和仓库补充粮秣，远离补给或持续作战会降低士气；断粮军团会撤退并逐步损失健康与幸福。
- 地图会显示军团旗帜、行军方向和补给条；军事面板可检查每支军团的将领、兵种和战役状态。
- 外交面板允许玩家以神力挑起战争或促成议和，并立即封锁或恢复相关跨国贸易。

## 贸易与物流

- 每个聚落拥有独立的粮食、木材和石料库存，并根据人口、建筑和战略需求计算目标储备、盈余、缺口与浮动价格。
- 市场、港口和仓库成熟后，聚落会寻找供需互补的国内或跨国伙伴，建立最多三条陆上或海上路线。
- 陆路会在可通行地形上寻路并优先利用道路；拥有港口的远距离伙伴可以开辟海运航线。路线和移动中的商队都会直接显示在地图上。
- 商队实际从出发地扣除货物，在抵达后补充目的地库存；跨国贸易采用双方都有库存支撑的实物交换，不会凭空生成资源。
- 战争会自动封锁交战国家之间的路线、停止新商队并威胁在途货物；议和后路线恢复通行。
- 物流面板展示畅通路线、在途商队、战争封锁、累计货运和交付次数，路线、商队与聚落库存均可单独检查。

## 种族与生态

- 人类：均衡发展，粮食生产与人口增长稳定。
- 精灵：寿命最长，擅长利用森林和生产木材。
- 矮人：寿命较长，采石效率和战斗能力突出。
- 兽人：寿命较短，但繁衍更快、战斗力更强，外交也更具攻击性。
- 野兔、野鹿和野猪共同消耗地表植被；赤狐捕食野兔，狼会追猎多种中小型动物，熊则处于陆地食物网顶层，极度饥饿的猛兽还可能袭击居民。
- 动物会衰老、挨饿、受伤和繁衍；低于安全种群时，在资源允许的情况下会发生外来迁徙，避免长期世界永久丢失食物链层级。

## 季节与环境

- 世界按春、夏、秋、冬循环，每一季拥有不同的气温、降水、植被生长、作物产能和繁殖倍率，地图也会随季节改变色调。
- 晴朗、降雨、风暴、热浪与霜冻会在季节约束下交替出现，短期改变产粮、生态恢复、动物消耗和居民生存成本。
- 每块地表会保存独立温度与湿度，并受到纬度、海岸、天气和局部天灾影响；气候面板展示世界平均湿度、肥力和当前作物产能。
- 湿润肥沃的草原会自然演替成森林，干热环境会让森林退化并推动荒漠化，焦土和沙地在条件改善后也能逐渐恢复。
- 洪水会提高地表湿度，干旱和热浪会快速抽干土壤；低湿森林在热浪中存在自然起火风险。

## 世界档案

- 三个独立手动存档槽位和一个自动存档槽位。
- 每 5 个纪元自动保存，可在档案馆中关闭。
- 新建世界可以输入最多 64 个字符的世界种子；相同种子与相同玩家操作会生成相同地图，并沿相同的生态、外交、战争和天灾随机序列演化。
- v13 存档包含世界种子和随机数状态，并为地表模拟值保留完整浮点精度，因此载入后会从保存点继续原时间线，而不是悄悄分叉。
- 存档包含地形、植被、土壤湿度与温度、季节天气、人口、阶层、动物、实体建筑及耐久、聚落库存与价格、贸易路线、在途商队、军团与将领、政体、政策、文化价值观、传统、科技等级与研究进度、国库、动乱、外交、战争、进行中的灾害、目标、成就、统计、编年史、随机状态、镜头与速度设置。
- 支持将完整世界导出为 JSON 文件，也可以从 JSON 文件导入。
- 旧版单槽存档会自动补全种族、生态和新版字段；版本 5 及更早的建筑数量会自动迁移为带坐标的实体建筑。

## 世界目标与历史

- 六个可选世界目标覆盖聚落、人口、建筑、贸易、灾后恢复与百年延续，目标只提供进度与世界声望，不限制沙盒工具。
- 十四项文明成就会记录首次贸易、同盟、战争、天灾、叛乱、科技突破、城市成长、生态完整度等里程碑及达成纪元。
- 世界统计持续累计出生与死亡、建造与损毁、商队交付、战争、天灾和聚落易手，并保存人口、文明与生态历史峰值。
- 近期事件用于快速观察，完整编年史最多保留 240 条记录，可单独导出为按纪元排列的文本档案。

## 天灾系统

- 世界会按“稀少、正常、频繁”三档概率自动发生天灾，也可以关闭随机天灾。
- 地震会伤害生命、削弱聚落防御、摧毁建筑并产生余震。
- 洪水会持续冲刷植被和肥力，使居民缺粮并损伤聚落。
- 龙卷风会在地图上移动，沿途伤害居民、动物、建筑和植被。
- 火山会形成火山口、覆盖焦土，并周期性抛射引燃物。
- 瘟疫会感染居民并在人群之间传播，受祝福的居民拥有免疫力和更快恢复速度。
- 干旱会降低植被、肥力和粮食储备，并增加森林起火风险。
- 所有新增天灾都可以从创世工具中手动释放，神力范围决定灾害强度与影响半径。

## 性能

- 人口与动物使用空间索引处理附近目标和捕食查询。
- 高频人口、聚落、王国、贸易路线和军团查询使用按帧索引；模拟每步只重建一次索引，建筑增删会直接增量更新空间索引，避免查询退化。
- 军团使用空间索引统计附近敌军，不再为每支军团扫描全部人口；生态模拟采用等价的自适应批处理，高实体数量时自动降低遍历频率。
- 地图绘制会裁剪视口外实体；底部性能监测实时显示 FPS、UPS、模拟耗时和绘制耗时。
- 暂停时停止重复重绘；高倍速掉帧时限制追赶步数，优先保持界面响应。

## 工程与测试

- `engine-core.js` 提供确定性随机数、数值、文本清理、噪声生成和实体压缩；`world-config.js` 集中管理静态规则与平衡参数。
- `game.js` 只保留世界状态与模拟规则；`game-ui.js` 负责检查面板和画布绘制；`game-persistence.js` 负责 v13 存档、旧档迁移与导入导出，页面按显式依赖顺序加载。
- `tests/headless-world.js` 会在无浏览器环境中启动真实游戏模拟，而不是另写一套简化规则；确定性测试覆盖同种子演化、异种子差异和存档随机时间线续接。
- 运行 `npm test` 执行确定性、核心工具、DOM 完整性、模块边界、存档版本与性能保护测试；运行 `npm run check` 会额外执行所有脚本语法检查。
- `npm run balance:quick` 用 4 个固定种子跑到纪元 50；`npm run balance` 用 12 个固定种子执行完整平衡门禁，检查人口异常、文明灭绝、种族垄断、饥荒、战争覆盖率和食物网完整度。
- GitHub Actions 会在每次推送和拉取请求时自动运行完整检查，无需安装第三方依赖。

## 运行

直接使用浏览器打开 `index.html`，或在本目录启动任意静态文件服务器：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 操作

- 左键：观察或使用当前神力
- 右键拖动：平移地图
- 鼠标滚轮：缩放地图
- 顶部按钮：暂停及调整时间速度
- 保存/读取：使用浏览器本地存储
