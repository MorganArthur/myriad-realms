# 万象之境

一款原创的像素世界模拟器。玩家可以塑造地形、创造居民、赐予祝福或降下灾难；居民会自行探索、建立聚落、形成王国并繁衍。

王国会围绕聚落采集粮食、木材与石料，并根据人口和资源建造住宅、农场、伐木场、采石场及兵营。不同王国之间会形成和平、同盟或战争关系；战争期间士兵会集结、进攻并占领敌方聚落。世界中同时存在会觅食、繁衍、捕猎和迁徙的野生动物生态。

## 视觉与交互

- 创世工具按观察塑形、文明种族、生态生物、神力天灾分组，悬停、选中与键盘聚焦状态使用统一的金色交互语言。
- 顶部统计、左右信息面板、世界画布与底部状态栏采用分层材质、柔和描边和受控阴影，重要信息更加突出。
- 地图加入确定性的地表微纹理、海岸高光、水面波纹、山地切面、村庄投影与屋顶轮廓；这些装饰不消耗随机数，不会影响世界种子的模拟结果。
- 鼠标经过地图会显示虚线格，观察过的地块会保留选中反馈，天灾和水域工具使用不同的提示色。
- 支持系统“减少动态效果”设置；窄屏布局会压缩侧栏和统计卡，保持地图为视觉中心。

## 创世指引与世界百科

- 七步交互式教程会引导玩家观察地图、选择工具、施展神力、启动时间并阅读世界纪事；可以跳过，也能通过顶部“？”随时重开。
- 世界百科按文明种族、生态生物、建筑设施、天灾和系统规则分类，直接使用正式配置生成条目，避免说明与实际规则脱节。
- 自然地貌、政治疆域、土地肥力、人口密度和外交关系五种地图模式提供不同的信息视角，并带有对应图例。

## 外交 AI 与历史记忆

- 国家关系会持续记录信任、戒惧、旧怨、战略意图和最近判断理由，而不再只依赖单一好感数值。
- 贸易往来、共同敌人、力量差距、边境接触、战争疲劳和世界事件都会影响结盟、遏制、开战与议和决策。
- 神力干预、联合行动和独占利益会写入双方外交记忆，并在后续关系演化中继续产生影响。

## 英雄与世界事件链

- 各文明可以涌现贤王、守望者、锻造大师、战团勇士、济世者和远行者；英雄拥有等级、声望、胜绩、文明加成和个人地图标记。
- 英雄会参与战斗、研究、治理、医疗与贸易，积累声望后升级；退出历史舞台后仍以传奇身份保留在编年史和英雄列表中。
- 星落之谜、万邦议会、灰穗之年、空王座之争、行会革命、圣火分裂、无乡者长路、远海航路、远古巨兽、火山神谕、失落之城和铁律竞逐组成十二条大型事件链；每条均有三章，每章提供三种选择。
- 事件会根据年代、文明数量、王朝、行会、信仰、贸易、生态、灾害与遗迹状态触发，并自动选出具有“东道国、宣称国、受灾国”等明确身份的参与文明。
- 选择不仅即时改变资源、研究、社会和外交，还能安排数年后才显现的后果、锁定互斥历史路线，并写入国家外交记忆、统治者人物记忆和世界编年史。
- 重大事件出现时会自动暂停世界，玩家选择后恢复此前的运行状态；批量模拟中则会由文明自动决策。

## 时代与文明野心

- 每个文明会依次经历火种纪、聚落纪、城邦纪、盛世纪与传奇纪。时代不会按年份自动解锁，而是综合检查人口、聚落、实体建筑、科技、合法性、贸易、英雄和已完成野心。
- 新时代会写入编年史并提供逐级增强的资源、科研、建造与军事实效；叛乱国家会继承母国之前一档的时代基础，而不是从完整巅峰起步。
- 文明可以追求一统山河、商路霸权、求知长明、文脉千秋、万物和鸣、不朽营造、铁血霸业与天下弭兵八类长期野心。
- 每项野心包含三个可见里程碑，达成单项会获得小型阶段奖励；完成整项野心会增加世界声望并形成永久传承，持续影响后续科研、生产、建造、战斗、外交或社会稳定。
- AI 会依据种族、现有资源、科技、文化、外交和军事局势选择下一项野心；玩家可在国家详情中引导方向，调整后锁定 12 个纪元，已经完成的野心不会重复刷取奖励。
- 世界纪事新增文明发展卡，可直接查看每个国家的当前时代、下一时代综合进度、当前野心和完成百分比；国家详情会展开所有硬性条件与永久传承。

## 王朝、继承与人物关系

- 每位居民拥有稳定姓名、性别、亲代、配偶、子女、家族归属和双向人物关系；亲近、信任、竞争及婚姻、出生、继承等共同记忆会随存档延续。
- 君主制、长老议会、行会共和国和氏族联盟分别以长嗣继承、宗族长老、贤能推举和强者继承起步；玩家可在国家详情中改革继承法，改革后锁定 15 个纪元。
- 每个国家会维护真实统治者、继承人、家族威望、宫廷凝聚、宣称者和历代统治记录。统治者死亡或任期结束时会依继承法完成交接，势均力敌的宣称可能触发继承危机。
- 幼年统治者会由最有影响力的成年人摄政，成年后自动亲政；共和、议会和氏族政体也会按任期举行换届、推举或挑战。
- 王朝威望、宫廷关系、统治者能力、摄政与继承争议会实际影响税收、合法性和社会稳定；叛乱政权会建立自己的统治家族，亡国王朝会留下末代记录。
- 世界纪事中的王朝卡可直接查看各国统治者、继承人、继承法、威望和危机状态；人物链接可继续追踪亲属、配偶、英雄身份与关系记忆。

## 派系、议会与内部政治

- 每个国家拥有宫廷派、民生派、行会派、信仰派和军功派。居民会依据阶层、职业、军职、英雄身份与政治地位为不同派系提供组织力量，市场、神殿、兵营、行政科技和文化价值也会改变派系影响力。
- 各政体分别召开御前会议、长老议庭、公民议会或氏族大会，席位总数不同；五派按照实时影响力分配全部席位，并从符合其社会基础的成年人中推举领袖。
- 派系支持率会同时响应幸福、合法性、税制、福利、战争、饥荒、贸易、军团士气、王朝威望与国家权威。长期失去支持会积累激进度，支持恢复后则会缓慢降温。
- 有影响力的派系会围绕税制、民生和军事方针提出正式议案。玩家可接受提案、推动中间政策或直接否决；若不干预，国家会在三纪元后依据财政、动乱、派系影响和权威自动决断。
- 议会凝聚、政权权威与制度腐败会实际改变税收效率、合法性和社会稳定；派系压力也会参与 AI 的日常政策选择，而不是只作为说明数值。
- 激进的军功派可能制造政变阴影，宫廷派会挑战继承秩序，民生派会推动地方抗命，行会派会罢市，信仰派会造成社会分裂。危机会写入人物关系、国家政治史和世界编年史。

## 区域事件、遗迹神器与世界奇观

- 三十条区域事件覆盖丰收、使团、行会、流民、矿难、港口、商路、林地、老兵、医师、税争、继承宴席、疫病疑云与英雄挑战等地方故事；它们会依据年代、贸易、港口、王朝、派系、文化、资源、生态和灾害条件，选择最符合情境的主导文明。
- 每条区域事件提供三种即时抉择，并与大型事件共用同一套资源、社会、外交、人物、生态和历史效果引擎；最近出现过的八条会暂时退出随机池，减少短期重复。玩家不干预时，文明会在约 2.5 个纪元后自行决定。
- 新世界会确定性生成六处地图遗迹。最近的文明会派出斥候并持续积累探索进度，远行者英雄、航运科技与星界罗盘能够加快考察。
- 群星观测台、余烬锻库、苍翠圣所和沉潮档案馆分别可能出土星界罗盘、泰坦铸锤、苍生之冠和万邦誓碑；神器拥有明确持有文明并实际影响研究、资源、健康、合法性或社会稳定。
- 进入城邦纪并积累足够建筑与木石的文明可以启动分阶段奇观工程。万卷穹庭、世界根花园、永恒熔炉和苍穹战垒会持续消耗资源、受工程科技和建筑师推动，完成后留在地图与编年史中。
- 灰烬长冬、赤雾疫潮、盟誓崩解、永涨潮汐、焚世旱火和万兽沉寂会作为全球危机施加持续压力。各文明会自动贡献粮食、医药、行政和合法性，玩家也能推动协调、赈济或全面动员；成功和失败都会留下永久世界遗产。
- 寻古、奇观、贸易与灾害守望挑战会轮换出现，使用开始时的真实世界统计作为基线，设有明确期限、进度与世界声望奖励。

- 神力、战斗、英雄诞生和世界事件拥有轻量粒子反馈，不进入存档，也不消耗世界种子的随机序列。
- 可选 Web Audio 合成音效覆盖按钮、神力、天灾、战斗、英雄和事件，并默认静音以遵守浏览器自动播放限制。

## 文明系统

- 资源：草原与农场生产粮食，森林与伐木场生产木材，山地与采石场生产石料；基础储粮能力随人口、聚落和农场增长，过量库存会自然损耗。
- 实体建筑：建筑拥有独立坐标、耐久、建造纪元和所属聚落，可在地图上直接观察；灾害、火灾和战争会损伤或摧毁具体建筑，建筑师会优先维修危房。
- 城市设施：住宅提高人口容量，农田、伐木场和采石场强化对应生产，兵营扩大正规军上限；道路加速移动和建设，城墙强化防御与安全，市场扩大商贸，港口提供水域粮食和贸易，神殿改善幸福、治疗与恢复。
- 仓储：仓库扩大三类聚落库存和商队装载量，同时提高国家储粮能力；建筑损毁后相应容量会立即下降。
- 城市生长：聚落会根据战争、住房、粮食、地形、人口和当前库存选择能够负担且有合法地块的建设项目，并把道路逐段延伸到外围设施。
- 职业：成年居民会根据聚落资源、建筑、疾病和战争需求，在农民、伐木工、矿工、建筑师、商人、治疗师与士兵之间动态分工；儿童成年后进入劳动力队伍。
- 民生：每位居民拥有营养、住所、安全与健康需求，工作、战争、灾害、拥挤和疾病会共同影响幸福度及生命状态。
- 饥荒：粮食按人口持续消耗，低储备会触发并逐步加剧饥荒，降低幸福度、健康和生育率；恢复安全储备后饥荒自动结束。
- 扩张：人口和资源充足的王国会派出拓荒者建立新聚落并扩张领土。
- 外交：边境摩擦、经济差距和随机事件会改变关系，国家能够结盟、宣战与议和；同盟提供贸易增益。
- 战争：国家会按人口与兵营进行战时动员，把士兵编入军团，由将领率领攻击敌军、围攻聚落和占领领土；失去全部聚落的王国将覆灭。

## 文化与科技

- 每个国家拥有独立文化名称与起源精神，并记录共同体、自然、技艺、尚武、商贸和信仰六类价值观；价值观会随政体、政策、职业、战争、森林和城市设施缓慢演变。
- 文明会根据农田、森林、矿业、军队、市场、港口、神殿和科技水平形成丰收礼俗、林地守望、石工秘传、勇士信条、商旅行会与济世教团，传统会提供永久的特色加成。
- 农耕学、工程学、冶金术、航运术、医药学和行政学各有三级研究，研究点由成年人口、工匠、治疗师、商人、聚落和文化精神共同产生。
- 科技不是展示数值：它会实际改变粮食和仓储、建筑成本与耐久、军队攻击与攻城、商队运量与速度、治疗与抗疫、税收与合法性。
- AI 会依据饥荒、战争、瘟疫、动乱和港口发展调整研究方向；玩家可在国家详情中点击科技，将研究方向锁定 10 个纪元。
- 跨国商队会带来文化交流，使双方价值观逐渐互相影响；叛乱政权会继承母国的部分传统和技术，同时形成新的文化名称。

## 国家与社会

- 人类、精灵、矮人和兽人国家分别以君主制、长老议会、行会共和国和氏族联盟起步；政权危机可能推动政体改组。
- 国家拥有国库、税收、合法性、福利覆盖与社会动乱；税制、民生和军事三组政策会同时影响财政、幸福、动乱与征兵规模。
- 居民会根据年龄、职业与军职形成权贵、商贾、匠师、平民、军户和眷属阶层，不同阶层对政体、税收和战争方针有不同反应。
- 玩家可在国家详情中直接调整政策，也能用神力安抚或煽动民心；AI 国家会依据财政、饥荒、战争与动乱自主修正政策。
- 长期低幸福、饥荒、重税、战争疲劳和福利断供会积累地方动乱。高动乱聚落可能脱离母国，带走居民、领土、物资与部分国库，并建立新政权发动内战。

## 军事系统

- 军团拥有集结地、战役目标、将领、士气、补给、伤亡与攻城进度，会在集结、推进、交战、围城和撤退之间切换。
- 民兵、步兵、弓手、骑兵和攻城兵拥有不同的攻击、防御、射程、速度、补给消耗与攻城能力；兵营、市场、伐木场和采石场会影响兵种编制。
- 军团从附近友方聚落和仓库补充粮秣，远离补给或持续作战会降低士气；断粮军团会撤退并逐步损失健康与幸福。
- 地图会显示军团旗帜、行军方向和补给条；军事面板可检查每支军团的将领、兵种和战役状态。
- 外交面板允许玩家以神力挑起战争或促成议和，并立即封锁或恢复相关跨国贸易。

## 贸易与物流

- 每个聚落拥有独立的粮食、木材和石料库存，并根据人口、建筑和战略需求计算目标储备、盈余、缺口与浮动价格。
- 市场、港口和仓库成熟后，聚落会寻找供需互补的国内或跨国伙伴，建立最多三条陆上或海上路线。
- 陆路会在可通行地形上寻路并优先利用道路；拥有港口的远距离伙伴可以开辟海运航线。路线和移动中的商队都会直接显示在地图上。
- 商队实际从出发地扣除货物，在抵达后补充目的地库存；跨国贸易采用双方都有库存支撑的实物交换，不会凭空生成资源。
- 战争会自动封锁交战国家之间的路线、停止新商队并威胁在途货物；议和后路线恢复通行。
- 物流面板展示畅通路线、在途商队、战争封锁、累计货运和交付次数，路线、商队与聚落库存均可单独检查。

## 种族与生态

- 人类：均衡发展，粮食生产与人口增长稳定。
- 精灵：寿命最长，擅长利用森林和生产木材。
- 矮人：寿命较长，采石效率和战斗能力突出。
- 兽人：寿命较短，但繁衍更快、战斗力更强，外交也更具攻击性。
- 野兔、野鹿和野猪共同消耗地表植被；赤狐捕食野兔，狼会追猎多种中小型动物，熊则处于陆地食物网顶层，极度饥饿的猛兽还可能袭击居民。
- 动物会衰老、挨饿、受伤和繁衍；低于安全种群时，在资源允许的情况下会发生外来迁徙，避免长期世界永久丢失食物链层级。

## 季节与环境

- 世界按春、夏、秋、冬循环，每一季拥有不同的气温、降水、植被生长、作物产能和繁殖倍率，地图也会随季节改变色调。
- 晴朗、降雨、风暴、热浪与霜冻会在季节约束下交替出现，短期改变产粮、生态恢复、动物消耗和居民生存成本。
- 每块地表会保存独立温度与湿度，并受到纬度、海岸、天气和局部天灾影响；气候面板展示世界平均湿度、肥力和当前作物产能。
- 湿润肥沃的草原会自然演替成森林，干热环境会让森林退化并推动荒漠化，焦土和沙地在条件改善后也能逐渐恢复。
- 洪水会提高地表湿度，干旱和热浪会快速抽干土壤；低湿森林在热浪中存在自然起火风险。

## 世界档案

- 三个独立手动存档槽位和一个自动存档槽位。
- 每 5 个纪元自动保存，可在档案馆中关闭。
- 新建世界可以输入最多 64 个字符的世界种子；相同种子与相同玩家操作会生成相同地图，并沿相同的生态、外交、战争和天灾随机序列演化。
- v22 存档包含世界种子、随机数状态、组合挑战规则、英雄、十二条大型事件链、三十条区域事件、事件参与者、路线锁定、延迟后果、文明时代、野心、人物关系、家谱、王朝、继承法、派系政治、历史伤痕、神器持有者与耐久、奇观损毁记录、六类后期危机及永久结局、全球危机与轮换挑战，并为地表模拟值保留完整浮点精度，因此载入后会从保存点继续原时间线，而不是悄悄分叉。
- 存档包含地形、植被、土壤湿度与温度、季节天气、人口、姓名、亲属、关系记忆、阶层、动物、实体建筑及耐久、聚落库存与价格、贸易路线、在途商队、军团与将领、政体、政策、文化价值观、传统、科技等级与研究进度、文明时代与野心、王朝继承、派系议会、遗产系统、国库、动乱、外交、战争、进行中的灾害、目标、成就、统计、编年史、随机状态、镜头与速度设置。
- 跨世界档案独立于四个存档槽，按一次世界运行记录种子、规则组合、纪元、人口、文明、成就、永久遗产与挑战分数；重复封存同一次运行会更新成绩，新建世界前会自动保留旧世界记录。
- 支持将完整世界导出为 JSON 文件，也可以从 JSON 文件导入。
- 旧版单槽存档会自动补全种族、生态和新版字段；版本 5 及更早的建筑数量会自动迁移为带坐标的实体建筑。

## 世界目标与历史

- 六个可选世界目标覆盖聚落、人口、建筑、贸易、灾后恢复与百年延续，目标只提供进度与世界声望，不限制沙盒工具。
- 二十六项文明成就会记录首次贸易、同盟、战争、天灾、叛乱、科技突破、城市成长、生态完整度、文明野心、传奇时代、婚姻、权力交接、议会决议、派系危机、神器、奇观、全球危机与世界挑战等里程碑及达成纪元。
- 世界统计持续累计出生与死亡、婚姻、权力交接、继承危机、议案决议、派系危机、动态抉择、遗迹探索、神器、奇观、全球危机、挑战、建造与损毁、商队交付、战争、天灾和聚落易手，并保存人口、文明与生态历史峰值。
- 近期事件用于快速观察，完整编年史最多保留 240 条记录，可单独导出为按纪元排列的文本档案。

## 天灾系统

- 世界会按“稀少、正常、频繁”三档概率自动发生天灾，也可以关闭随机天灾。
- 地震会伤害生命、削弱聚落防御、摧毁建筑并产生余震。
- 洪水会持续冲刷植被和肥力，使居民缺粮并损伤聚落。
- 龙卷风会在地图上移动，沿途伤害居民、动物、建筑和植被。
- 火山会形成火山口、覆盖焦土，并周期性抛射引燃物。
- 瘟疫会感染居民并在人群之间传播，受祝福的居民拥有免疫力和更快恢复速度。
- 干旱会降低植被、肥力和粮食储备，并增加森林起火风险。
- 所有新增天灾都可以从创世工具中手动释放，神力范围决定灾害强度与影响半径。

## 遗迹、神器与奇观

- 战争、聚落陷落、六类天灾、英雄离世以及港口、道路和矿井毁坏会在真实发生的位置形成十二类历史伤痕，而不是随机摆放一条背景文字。
- 文明或创世者可以考证、重建、圣化或争夺这些遗址；选择会改变研究、文化、合法性、动乱、外交记忆与世界统计。
- 神器会进入国库或交由活跃英雄携带，能够在灾难中受损、在王国覆灭后被夺取或失落，也可以从关联遗址中重新出土；效果会随耐久降低。
- 奇观拥有独立耐久，在攻城、天灾或建造文明覆灭时会受损甚至成为废墟，所属文明可投入木材、石料和国库逐步修复。

## 后期世界危机

- 六类后期危机包括灰烬长冬、赤雾疫潮、盟誓崩解、永涨潮汐、焚世旱火与万兽沉寂，并按时代门槛从纪元 22 后逐步进入自然事件池。
- 每类危机都拥有成功与失守两种互斥永久结局，共十二种世界遗产；它们会持续修正粮食、资源、健康、研究、合法性、动乱、外交信任或动物恢复能力。
- 危机结局不只记录在文本里：永涨潮汐失守会永久淹没安全范围外的低地海岸，焚世旱火失守会形成焦土带，盟誓结局会直接改写国家间的信任、旧怨和关系分数。
- 危机遗产会显示在“危机与挑战”面板，完整写入存档，并在载入后继续影响同一条世界时间线。

## 组合挑战与世界档案

- 资源匮乏、严酷气候、天灾无休、诸国猜忌、脆弱生态与知识长夜六项规则可以任意组合，分别改变初始资源、生产、健康、外交、天灾频率与强度、生态恢复和研究速度。
- 所选规则会累加难度点数，并按难度提高世界成绩倍率；标准沙盒不启用任何惩罚或加成。
- 挑战码同时编码世界种子和规则组合，可以复制分享；载入相同挑战码会生成相同初始世界，并沿同一确定性随机时间线演化。
- 跨世界档案可以比较不同规则和不同种子的运行成绩，也能一键把历史记录中的种子与规则重新载入创世面板。

## 性能

- 人口与动物使用空间索引处理附近目标和捕食查询。
- 高频人口、聚落、王国、贸易路线和军团查询使用按帧索引；模拟每步只重建一次索引，建筑增删会直接增量更新空间索引，避免查询退化。
- 时代和野心共用按模拟帧缓存的世界统计，一次遍历汇总森林、商路、交付与英雄，不会为每个文明或每张界面卡重复扫描整张地图。
- 军团使用空间索引统计附近敌军，不再为每支军团扫描全部人口；生态模拟采用等价的自适应批处理，高实体数量时自动降低遍历频率。
- 地图绘制会裁剪视口外实体；底部性能监测实时显示 FPS、UPS、模拟耗时和绘制耗时。
- 暂停时停止重复重绘；高倍速掉帧时限制追赶步数，优先保持界面响应。

## 工程与测试

- `engine-core.js` 提供确定性随机数、数值、文本清理、噪声生成和实体压缩；`world-config.js` 集中管理静态规则与平衡参数；`world-event-content.js` 和 `regional-event-content.js` 分别保存十二条大型事件与三十条区域事件的纯数据定义；`experience-system.js` 管理教程、外交记忆、英雄、事件执行、地图模式、特效和音频；`long-term-system.js` 管理文明时代、野心、里程碑与传承效果；`dynasty-system.js` 管理人物身份、家谱、关系、王朝、继承与摄政；`politics-system.js` 管理派系、议会、政策议题与内部危机；`legacy-system.js` 管理区域事件调度、历史伤痕、神器流转、奇观耐久、全球危机与轮换挑战；`world-challenge-system.js` 管理组合规则、挑战码、评分和跨世界档案。
- `game.js` 只保留世界状态与模拟规则；`game-ui.js` 负责检查面板和画布绘制；`game-persistence.js` 负责 v22 存档、旧档迁移与导入导出，页面按显式依赖顺序加载。
- `tests/headless-world.js` 会在无浏览器环境中启动真实游戏模拟，而不是另写一套简化规则；确定性测试覆盖同种子演化、异种子差异、事件链参与者与互斥路线、延迟后果和存档随机时间线续接。
- 运行 `npm test` 执行确定性、核心工具、DOM 完整性、模块边界、存档版本与性能保护测试；运行 `npm run check` 会额外执行所有脚本语法检查。
- `npm run balance:quick` 用 5 个固定种子跑到纪元 50；`npm run balance` 用 12 个固定种子执行完整平衡门禁，检查人口异常、文明灭绝、种族垄断、饥荒、战争覆盖率和食物网完整度。
- GitHub Actions 会在每次推送和拉取请求时自动运行完整检查，无需安装第三方依赖。

## 运行

直接使用浏览器打开 `index.html`，或在本目录启动任意静态文件服务器：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

- 右键拖动：平移地图
- 鼠标滚轮：缩放地图
- 顶部按钮：暂停及调整时间速度
- 保存/读取：使用浏览器本地存储
