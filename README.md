# 万象之境

一款原创的像素世界模拟器。玩家可以塑造地形、创造居民、赐予祝福或降下灾难；居民会自行探索、建立聚落、形成王国并繁衍。

王国会围绕聚落采集粮食、木材与石料，并根据人口和资源建造住宅、农场、伐木场、采石场及兵营。不同王国之间会形成和平、同盟或战争关系；战争期间士兵会集结、进攻并占领敌方聚落。世界中同时存在会觅食、繁衍、捕猎和迁徙的野生动物生态。

## 文明系统

- 资源：草原与农场生产粮食，森林与伐木场生产木材，山地与采石场生产石料；基础储粮能力随人口、聚落和农场增长，过量库存会自然损耗。
- 实体建筑：建筑拥有独立坐标、耐久、建造纪元和所属聚落，可在地图上直接观察；灾害、火灾和战争会损伤或摧毁具体建筑，建筑师会优先维修危房。
- 城市设施：住宅提高人口容量，农田、伐木场和采石场强化对应生产，兵营扩大正规军上限；道路加速移动和建设，城墙强化防御与安全，市场扩大商贸，港口提供水域粮食和贸易，神殿改善幸福、治疗与恢复。
- 仓储：仓库扩大三类聚落库存和商队装载量，同时提高国家储粮能力；建筑损毁后相应容量会立即下降。
- 城市生长：聚落会根据战争、住房、粮食、地形、人口和当前库存选择能够负担且有合法地块的建设项目，并把道路逐段延伸到外围设施。
- 职业：成年居民会根据聚落资源、建筑、疾病和战争需求，在农民、伐木工、矿工、建筑师、商人、治疗师与士兵之间动态分工；儿童成年后进入劳动力队伍。
- 民生：每位居民拥有营养、住所、安全与健康需求，工作、战争、灾害、拥挤和疾病会共同影响幸福度及生命状态。
- 饥荒：粮食按人口持续消耗，低储备会触发并逐步加剧饥荒，降低幸福度、健康和生育率；恢复安全储备后饥荒自动结束。
- 扩张：人口和资源充足的王国会派出拓荒者建立新聚落并扩张领土。
- 外交：边境摩擦、经济差距和随机事件会改变关系，国家能够结盟、宣战与议和；同盟提供贸易增益。
- 战争：国家会征召民兵与正规军，攻击敌军、围攻聚落、占领领土，失去全部聚落的王国将覆灭。

## 贸易与物流

- 每个聚落拥有独立的粮食、木材和石料库存，并根据人口、建筑和战略需求计算目标储备、盈余、缺口与浮动价格。
- 市场、港口和仓库成熟后，聚落会寻找供需互补的国内或跨国伙伴，建立最多三条陆上或海上路线。
- 陆路会在可通行地形上寻路并优先利用道路；拥有港口的远距离伙伴可以开辟海运航线。路线和移动中的商队都会直接显示在地图上。
- 商队实际从出发地扣除货物，在抵达后补充目的地库存；跨国贸易采用双方都有库存支撑的实物交换，不会凭空生成资源。
- 战争会自动封锁交战国家之间的路线、停止新商队并威胁在途货物；议和后路线恢复通行。
- 物流面板展示畅通路线、在途商队、战争封锁、累计货运和交付次数，路线、商队与聚落库存均可单独检查。

## 种族与生态

- 人类：均衡发展，粮食生产与人口增长稳定。
- 精灵：寿命最长，擅长利用森林和生产木材。
- 矮人：寿命较长，采石效率和战斗能力突出。
- 兽人：寿命较短，但繁衍更快、战斗力更强，外交也更具攻击性。
- 野兔与野鹿消耗地表植被；狼和熊追踪并捕食草食动物，极度饥饿时还可能袭击居民。
- 动物会衰老、挨饿、受伤和繁衍；低于安全种群时，在资源允许的情况下会发生外来迁徙，避免长期世界永久丢失食物链层级。

## 世界档案

- 三个独立手动存档槽位和一个自动存档槽位。
- 每 5 个纪元自动保存，可在档案馆中关闭。
- 存档包含地形、植被、人口、动物、实体建筑及耐久、聚落库存与价格、贸易路线、在途商队、资源、外交、战争、进行中的灾害、镜头与速度设置。
- 支持将完整世界导出为 JSON 文件，也可以从 JSON 文件导入。
- 旧版单槽存档会自动补全种族、生态和新版字段；版本 5 及更早的建筑数量会自动迁移为带坐标的实体建筑。

## 天灾系统

- 世界会按“稀少、正常、频繁”三档概率自动发生天灾，也可以关闭随机天灾。
- 地震会伤害生命、削弱聚落防御、摧毁建筑并产生余震。
- 洪水会持续冲刷植被和肥力，使居民缺粮并损伤聚落。
- 龙卷风会在地图上移动，沿途伤害居民、动物、建筑和植被。
- 火山会形成火山口、覆盖焦土，并周期性抛射引燃物。
- 瘟疫会感染居民并在人群之间传播，受祝福的居民拥有免疫力和更快恢复速度。
- 干旱会降低植被、肥力和粮食储备，并增加森林起火风险。
- 所有新增天灾都可以从创世工具中手动释放，神力范围决定灾害强度与影响半径。

## 性能

- 人口与动物使用空间索引处理附近目标和捕食查询。
- 高频人口、聚落和王国查询使用按帧缓存。
- 生态模拟采用隔帧批处理，地图绘制会裁剪视口外实体。
- 暂停时停止重复重绘；高倍速掉帧时限制追赶步数，优先保持界面响应。

## 运行

直接使用浏览器打开 `index.html`，或在本目录启动任意静态文件服务器：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 操作

- 左键：观察或使用当前神力
- 右键拖动：平移地图
- 鼠标滚轮：缩放地图
- 顶部按钮：暂停及调整时间速度
- 保存/读取：使用浏览器本地存储
