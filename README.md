# 万象之境（Myriad Realms）

一个无需安装、直接在浏览器中运行的原创像素世界模拟器。当前版本刻意回到简单的沙盒机制：观察地图、生命、聚落、王国关系与天灾自行演化，需要时再用创世工具轻轻干预。

## 如何运行

直接双击 `index.html` 即可游玩。项目不依赖服务器、构建工具或第三方运行库，声音也由浏览器实时生成。

地图操作：

- 左键：观察或使用当前创世工具
- 右键拖动：移动地图
- 滚轮：缩放地图
- 顶栏：暂停以及 1×、2×、4× 速度

## 当前保留的核心系统

- 120×80 的确定性像素地图，同一种子生成相同初始世界
- 草地、森林、水域、丘陵、山地、雪地、肥力、湿度与自然恢复
- 人类、精灵、矮人、兽人四类居民，包含健康、幸福、年龄、繁衍和迁移
- 野兔、鹿、野猪、赤狐、狼、棕熊组成的简化生态关系
- 聚落自动积累食物、木材和石料，并按需求建造民居、农田、资源设施、道路、集市、仓库、神殿等
- 王国之间的和平、同盟和抽象冲突；结果直接作用于资源、居民状态和聚落归属
- 地震、洪水、龙卷风、火山、瘟疫、干旱六类随机与手动天灾
- 春夏秋冬、晴雨、风暴、热浪和霜冻
- 三个信息页：世界概览、王国与外交、天灾与历史
- 三槽本地存档、自动保存、JSON 导入导出和旧存档核心数据迁移
- 程序化背景音乐、自然环境声和通用事件音效

## 精简原则

v0.23.0 是一次有意的结构收缩。项目已经彻底移除成就与目标、声望、英雄、职业和社会阶层、实体商队与路线、军团与兵种、武器动作和攻城流程，以及依赖这些对象的时代挑战、遗产、王朝、派系和大型抉择事件。

这些内容不是在界面里隐藏，而是从运行时状态、模拟循环、绘制器、声音目录、存档结构、脚本加载链、测试与内容图集中一并删除。国家冲突仍存在，但只是宏观关系和结果结算，不产生可操控单位。

## 项目结构

| 文件 | 作用 |
| --- | --- |
| `engine-core.js` | 确定性随机数、噪声与通用工具 |
| `world-config.js` | 唯一世界配置和平衡参数 |
| `game.js` | 核心模拟循环与创世工具 |
| `pixel-art-system.js` | 核心对象的像素绘制 |
| `game-ui.js` | 画布交互与三个信息页 |
| `game-persistence.js` | v23 存档、导入导出与旧档迁移 |
| `audio-system.js` | 程序化音乐、环境声和事件反馈 |
| `experience-system.js` | 新手指引、百科、声音与档案弹窗 |

## 验证

需要 Node.js 22 或更高版本：

```bash
npm run check
npm run balance:quick
```

`npm run check` 会做语法、确定性、六类天灾、抽象国家关系、存档迁移、像素/音频接口和项目完整性检查。平衡门禁会在多个固定种子上运行到纪元 50，检查人口、生态、聚落、王国、饥饿、冲突和随机天灾。

## 数据与性能

- 世界上限为 650 名居民和 370 只动物。
- 只有核心实体进入模拟，面板以较低频率刷新。
- 地图按可见区域绘制，缩放较远时跳过不必要的细节。
- 存档版本为 23；旧档载入时会保留兼容的核心数据，退役字段不会进入新世界。

本项目是原创沙盒原型，与其他商业游戏没有从属关系，也不包含其美术、代码或商标资源。
