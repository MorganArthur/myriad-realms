# 数值平衡基线

本报告记录 v0.10.0 的固定种子回归基线。测试直接加载正式的 `engine-core.js`、`world-config.js`、`game-ui.js`、`game-persistence.js` 和 `game.js`，每个样本从纪元 1 推进到纪元 50；随机天灾保持开启。

## 最终结果

完整门禁使用 `balance-01` 至 `balance-12` 共 12 个固定种子：

- 人口：最少 27，平均 39.42，最多 63，异常样本率 0%。
- 文明：四文明存续率 100%，世界人口灭绝率 0%。
- 生态：平均动物 142.75，六层食物网完整率 83.33%。
- 战争：3/12 个世界在纪元 50 前发生过战争，覆盖率 25%；纪元 50 时 1 个世界仍在交战。
- 社会：饥荒国家占全部活跃国家的 2.08%。
- 多样性：各世界最大种族占比的平均值为 47.10%，未形成普遍的单一种族垄断。

## 门禁阈值

阈值集中保存在 `world-config.js` 的 `balance.targets`：

- 纪元 50 人口期望区间 25–90，区间外样本不得超过 20%。
- 人口灭绝率不得超过 10%，四文明存续率不得低于 80%。
- 完整食物网率不得低于 75%。
- 最大种族平均占比不得超过 65%，饥荒国家占比不得超过 25%。
- 发生过战争的世界应处于 15%–90%，避免完全和平或持续混战。

## 本轮调参

外交关系不再把所有未接壤国家都视为天然远交对象：55 格以内的近邻漂移为 0，真正远方国家仍获得 +1 的自然缓和；宣战阈值由 -42 调整为 -40。边境摩擦、战争疲劳与强制议和规则保持原强度。该中间值让战争覆盖率达到 25%，同时没有降低人口与文明存续门禁。

执行方式：

```powershell
npm run balance:quick
npm run balance
```
