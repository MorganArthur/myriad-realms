# 数值平衡基线

本报告记录 v0.12.0 的固定种子回归基线。测试直接加载正式的 `engine-core.js`、`world-config.js`、`experience-system.js`、`game-ui.js`、`game-persistence.js` 和 `game.js`，每个样本从纪元 1 推进到纪元 50；随机天灾、外交记忆、英雄和世界事件链保持开启。

## 最终结果

完整门禁使用 `balance-01` 至 `balance-12` 共 12 个固定种子：

- 人口：最少 23，平均 37.42，最多 53，异常样本率 8.33%。
- 文明：四文明存续率 100%，世界人口灭绝率 0%。
- 聚落：平均每个世界 5.17 个聚落。
- 生态：平均动物 162.58，六类动物组成的完整食物网存续率 100%。
- 战争：4/12 个世界在纪元 50 前发生过战争，覆盖率 33.33%；纪元 50 时所有战争均已结束。
- 社会：活跃国家饥荒率 0%。
- 多样性：各世界最大种族占比的平均值为 50.13%，未形成普遍的单一种族垄断。

## 门禁阈值

阈值集中保存在 `world-config.js` 的 `balance.targets`：

- 纪元 50 人口期望区间 25–90，区间外样本不得超过 20%。
- 人口灭绝率不得超过 10%，四文明存续率不得低于 80%。
- 完整食物网率不得低于 75%。
- 最大种族平均占比不得超过 65%，饥荒国家占比不得超过 25%。
- 发生过战争的世界应处于 15%–90%，避免完全和平或持续混战。

## 本轮调参

外交 AI 使用关系分数、信任、戒惧、旧怨和战略意图共同决策。信任会回归由关系、贸易、联盟和共同敌人决定的目标值，避免世界事件带来的合作增益永久累积；接壤、扩张政策、尚武文化和旧怨形成最高 14 点升级压力。基础宣战阈值调整为 -34，最终战争覆盖率为 33.33%，同时战争均能在疲劳机制下结束。

新增系统改变了模拟随机序列并使低人口样本增多，因此基础出生概率由 0.28% 调整为 0.36%。正式门禁的人口均值为 37.42，只有 1/12 个世界低于期望区间，最高人口 53，仍显著低于 90 的上限。快速门禁由 4 个扩展为 5 个固定种子，避免单个异常样本直接形成 25% 的离散误差。

执行方式：

```powershell
npm run balance:quick
npm run balance
```
