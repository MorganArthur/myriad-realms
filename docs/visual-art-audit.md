## 设计与性能约束

- 地形纹理和微动画由世界坐标确定，不消费模拟随机数；所有新效果只读取正式状态，不改变战斗、灾害或资源数值。
- 支持 `prefers-reduced-motion`；环境动画使用自适应 125/220/320ms 绘制间隔，战斗效果最多保留 120 个并按寿命清理。
- 三张图集通过 CSS 背景定位按需加载；英雄、神器、奇观和事件的 26 个画格均在 `tests/visual-art-preview.html` 中完成浏览器裁切检查。
- 地形热路径不再为每个地图格保存与恢复整套 Canvas 状态，只显式复位透明度，降低大地图重复绘制开销。

## 发布门禁

- `npm run check`：脚本语法、图集文件、内容映射、正式界面接入、确定性与 v22 存档回归。
- `npm run balance`：12 个固定种子推进至纪元 50，确保纯视觉发布未改变模拟基线。
- 浏览器回归：正式首页依赖加载与性能状态；无模拟回归页逐格检查英雄、神器、奇观和大型事件插图。
